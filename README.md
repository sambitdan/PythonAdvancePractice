# 🐍 Python Advanced Practice

A hands-on Python repository covering advanced Python concepts, Object-Oriented Programming, asynchronous programming, APIs, web scraping, data validation, multithreading, testing, and practical data-engineering-oriented examples.

The purpose of this repository is to learn Python concepts through **practical examples, experiments, and small projects** rather than only theoretical explanations.

---

## 📚 Topics Covered

- Python Basics & OOP
- Constructors
- Encapsulation
- Data Classes
- Class Methods
- Inheritance
- Polymorphism
- Decorators
- Pandas Decorators
- Multithreading
- Pydantic
- Asynchronous Programming
- APIs
- Web Scraping
- JSON / CSV / TSV / Parquet
- Pytest
- Python Modules
- Practical Data Engineering Concepts
